# Predictive Maintenance using Machine Learning

This project predicts equipment failure using machine learning and deep learning
models on sensor data and provides explainable AI insights using LIME for model transparency.

## Models Used
- LSTM (time-series prediction)
- XGBoost (classification)
- LIME (model explainability)

## Project Files
- `train_lstm.py` – trains the LSTM model
- `train_xgboost.py` – trains the XGBoost classifier
- `simulate_data.py` – generates synthetic sensor data
- `explain_lime.py` – explains predictions using LIME
- `lime_explanation.html` – visual explanation output

## Technologies
- Python
- NumPy, Pandas
- TensorFlow
- XGBoost
- Scikit-learn
- LIME


## Use Case
Predictive maintenance for industrial machines to reduce downtime
and improve operational efficiency.
